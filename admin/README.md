# Админка Kitsu — шаблон v4 «Пульт лисьего огня»

Интерактивный шаблон панели управления для
[kitsu-enterprise-site](https://github.com/Montihx/kitsu-enterprise-site).
Открывается без сборки: `admin/index.html`.

**Перед переносом прочитайте [docs/HANDOFF.md](docs/HANDOFF.md).** Там карта
разделов, все запросы к API, находки в бэкенде (что в текущем дашборде не
работает или работает не так, как подписано) и объяснение каждого упрощения.

## Коротко

- 7 разделов вместо 20 плоских экранов: Пульт, Каталог, Очереди, Парсер,
  Стенд, Люди, Настройки. Адреса `#/раздел/страница`.
- Палитры «Сакура» и «Обсидиан», светлая и тёмная темы; переключатели внизу
  левой панели. Время везде по Алматы, сервер получает UTC.
- `Ctrl+K` или `/` — поиск по страницам, тайтлам, операциям и людям.
- Запросы не отправляются: кнопка с последствиями показывает точный запрос и
  честно сообщает, что это макет.

## Состав

- `index.html` — каркас;
- `styles.css` — оформление поверх `../tokens.css`;
- `app.js` — экраны, панели, подтверждения, поиск;
- `data.js` — демонстрационные данные в формате ответов API;
- `contracts.js` — запросы, реальные права, время, cron, проверка форм;
- `tools/qa.mjs` — статические проверки (`npm run check`);
- `fonts/`, `vendor/` — локальные шрифты и Lucide с лицензиями.
