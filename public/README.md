# Kitsu Public — Anime Graphite

Автономный интерактивный redesign двух ключевых публичных экранов Kitsu в одной системе с административным шаблоном Anime Graphite:

- `index.html` — главная: hero, продолжение просмотра, каталог, расписание и обновления аниме, сезон и публичные коллекции;
- `anime.html` — тайтл: метаданные, список пользователя, реальные поля счётчиков, адаптивные уведомления, плеер, отдельный выбор источника и перевода, серии и комментарии.

## Запуск

Откройте `index.html` в современном браузере. Сборка и сервер не требуются. CSS, JavaScript, Lucide и шрифты находятся внутри проекта.

Постеры загружаются по внешним URL, которые в production заменяются значениями `poster_url` и `cover_url` из API. При недоступной сети макет сохраняет геометрию и показывает нейтральное состояние изображения.

## Что работает автономно

- тёмная и светлая темы с сохранением выбора;
- встроенный в header поиск без modal-окна: быстрые запросы и результаты раскрываются под полем; доступны `/`, `↑`, `↓`, `Enter`, `Esc`;
- desktop popover, mobile drawer и нижняя мобильная навигация;
- вкладки каталога и расписания;
- полноширинный desktop hero-слайдер с размытым фоном, отдельным фокусным артом и разнесёнными controls; на mobile — самостоятельная image-first композиция; пять слайдов, 7-секундная автопрокрутка, pause, стрелки, точки, клавиатура и свайп;
- горизонтальная лента «Продолжить смотреть» по принципу production-компонента: карточки `16:9`, оставшееся время, процент и прогресс поверх кадра, название и серия под ним, удаление и scroll-snap навигация;
- пятистатусные закладки: на desktop анимированный overlay полностью заполняет границы постера, на mobile используется bottom sheet; явное удаление, полноширинная нижняя полоска, синхронизация одинаковых тайтлов и локальное сохранение сохранены;
- страница тайтла с одинаковой информационной логикой на всех ширинах: poster-first mobile hero, быстрые действия, реальные `favorites_count`/`comments_count` и естественные строки фактов «иконка + готовый текст» без таблиц и разделителей;
- локальные list/subscription states; desktop-колокольчик под постером открывает компактный анимированный dropdown, на mobile тот же выбор становится bottom sheet и вызывается справа сверху; отдельные share и повторная карточка подробностей удалены;
- раскрытие описания и dialogs с названиями/настройками; player settings на mobile открываются как bottom sheet и содержат только подтверждённые quality/speed/mode/auto-next/skip controls;
- независимый выбор видеоисточника и перевода;
- состояния play/pause, mute, fullscreen и выбор серии;
- плиточный/списочный вид серий и поэтапная загрузка до 74 эпизодов;
- анимированный индикатор активной вкладки (каталог, дни расписания) и scroll-reveal для карточных лент;
- секция «Сезон» с иконкой и подписью по текущему месяцу (зима/весна/лето/осень), подготовленная под `season=current`;
- focus trap, возврат фокуса, skip-link и `prefers-reduced-motion` (анимации отключаются полностью).

Статические данные нужны только для демонстрации композиции. Макет не вызывает production API и не выдаёт локальное изменение за server mutation. Маршруты и поля, на которые рассчитан перенос, перечислены в `docs/ROUTE_DATA_MATRIX.md`.

## Визуальное направление

- Dark: canvas `#0D0D0F`, sidebar `#111113`, surface `#19191C`, светлая primary-кнопка.
- Light: canvas `#F5F4F2`, белые поверхности, primary `#1F1D20`.
- Фиолетовый accent (`#7242E0` dark / `#36255C` light) применяется для identity/focus/selection, а не как фоновая заливка.
- Green, amber, red и slate-blue используются только семантически.
- Публичные страницы медийнее dashboard, но сохраняют те же токены, радиусы, типографическую дисциплину и спокойную плотность.

## Состав проекта

- `index.html`, `anime.html` — автономные страницы;
- `styles.css` — общие токены, компоненты, темы и responsive rules;
- `app.js` — общая интерактивность без внешнего runtime;
- `fonts/`, `vendor/` — локальные зависимости и лицензии;
- `tools/qa.mjs`, `qa-results.json` — воспроизводимая статическая проверка;
- `AGENT_HANDOFF.md` — обязательный handoff для production-переноса;
- `docs/` — дизайн-система, route/data matrix, аудит соответствия, план и QA.

## Проверка

```bash
node --check app.js
node tools/qa.mjs --write
```

Финальный статический прогон: `46/46` проверок. Проверены структура HTML/CSS, локальные ссылки, ID/ARIA-связи, обязательные атрибуты, темы, увеличенная адаптивная плотность постеров `9/8/7/5/4/3`, поиск шириной исходного header-поля с фильтрами/недавними/результатами, внутренний bookmark overlay, hero-слайдер с центральным sharp-art `1600 px`, симметричной маской краёв и safe-area основного проекта, горизонтальная лента продолжения просмотра, страница тайтла, поля `favorites_count`/`comments_count`, адаптивное размещение уведомлений, отсутствие share/дублирующих подробностей, настройки плеера, локальные шрифты, контраст и ключевые JS-сценарии. Представительные пары цветов имеют контраст не ниже `4.97:1`.

Браузерный прогон `95/95` (`58` regression + `37` целевых) остаётся baseline предыдущей визуальной ревизии. Для текущей композиции hero/continue/title обязательна повторная matrix на ширинах `1440`/`1100`/`900`/`768`/`700`/`390 px`; baseline не считается доказательством текущего responsive layout.

Перед production merge обязательны повторный аудит фактической ветки, `pnpm` gates проекта и browser/Playwright QA на реальных данных. Код текущей ветки имеет приоритет над документацией этого архива.
