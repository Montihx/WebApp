# Публичный сайт Kitsu — «Сакура» и «Обсидиан»

Интерактивный шаблон двух публичных экранов Kitsu. Открывается без сборки.

- `index.html` — главная: слайдер, продолжение просмотра, каталог, расписание и обновления, сезон и коллекции;
- `anime.html` — тайтл: метаданные, список пользователя, плеер с выбором озвучки, серии, связанные тайтлы и комментарии.

## Поведение

- полноширинный desktop hero-слайдер с размытым фоном и отдельным фокусным артом; на mobile — самостоятельная image-first композиция; пять слайдов, 9-секундная автопрокрутка и единственная нижняя полоса прогресса. Стрелки доступны только шире `720 px`; на телефоне — свайпы без навигационных кнопок. Клавиатура сохранена. Кнопка паузы, точки, счётчик и «О тайтле» удалены. После касания, фокуса или ручного переключения автопрокрутка останавливается до перезагрузки страницы; при reduced-motion она не запускается.

Палитры «Сакура» (по умолчанию) и «Обсидиан», светлая и тёмная темы. Если постер не загрузился, вместо него рисуется генеративная обложка.

## Состав

- `styles.css` — основа: компоненты, темы, адаптив;
- `kitsu-v3.css` — слой оформления v3 поверх основы;
- `app.js`, `content.js`, `content-model.js` — интерактивность и демонстрационные данные;
- `fonts/`, `vendor/` — локальные шрифты и Lucide с лицензиями;
- `tools/qa.mjs`, `qa-results.json` — статическая проверка (`npm run check`).
