# Visual reference matrix

Эта матрица фиксирует не внешний вид для копирования, а конкретные принципы, по которым собрана арт-дирекция публичного шаблона Kitsu.

| Референс | Что используется | Что намеренно не переносится |
|---|---|---|
| AniList | Плотность метаданных, цветовая семантика статусов, быстрый обзор библиотеки | Синяя доминанта и мелкая карточная сетка |
| Letterboxd | Постер как главный носитель, спокойная типографика фактов, личная активность | Зелёный фирменный акцент и киноспецифичные паттерны |
| Crunchyroll | Медиа-first hero, ясная кнопка просмотра, сезонные подборки | Оранжевая брендовая заливка и рекламная плотность |
| Netflix | Крупное изображение, контрастный градиент текста, горизонтальные истории | Автовоспроизведение видео и чрезмерно плотные ряды |
| Apple TV | Воздух, мягкие материалы, крупные радиусы медиаповерхностей | Стекло на каждом контроле и системная iOS-композиция |
| Plex | Разделение библиотеки и продолжения просмотра | Утилитарная боковая навигация медиасервера |
| MUBI | Редакционная подача коллекций и выразительная типографика | Аскетизм, который скрывает полезные аниме-метаданные |
| Linear | Тональная иерархия вместо рамок, спокойные компактные контролы | Корпоративная холодность продуктового интерфейса |
| Raycast | Чёткая клавиатурная навигация, быстрые popover-поверхности | Командная палитра как основная навигация сайта |
| Radix UI | Предсказуемые focus/keyboard состояния и корректные меню | Внешний вид компонентов по умолчанию |
| GitHub Primer | Системность токенов, состояния и доступность | Плотность интерфейса разработчика |
| Apple HIG | Визуальная иерархия, touch targets, reduced motion | Прямое копирование нативных компонентов |
| Material Design 3 | Семантика контейнеров, состояний и bottom sheet | Тяжёлые elevated-карточки вокруг каждого блока |
| Refactoring UI | Иерархия через размер, вес, цвет и расстояние | Универсальный SaaS-вид без медийного характера |
| Laws of UX | Группировка, узнаваемые цели, ограниченный выбор в одном контексте | Декоративные паттерны без пользовательской задачи |
| Kanmi Anime Dashboard | Тематическая навигация и аниме-контент в дашборде | Неоновая перегрузка и шаблонная glassmorphism-сетка |
| Eclipse Streaming UI Kit | Масштаб медиаповерхностей и последовательность экранов | Унифицированные демонстрационные карточки |
| Оригинальный Kitsu Enterprise | Центральный sharp-art 1600 px, поиск под строкой, естественные строки метаданных | Незавершённые формы, декоративные частицы и случайные hover-эффекты |

## Правила результата

1. Контент и изображение формируют композицию; рамка используется только как реальная граница интерактивной поверхности.
2. Страница получает собственный ритм: расписание — временная линия, обновления — хронология, коллекции — визуальные эссе, профиль — личный обзор.
3. Постеры держатся в диапазоне примерно 180–200 px на обычном desktop, не раздуваются из-за малого числа карточек и сохраняют три колонки на типичном телефоне.
4. Рейтинг не занимает место на постерной карточке; под названием показывается прогресс/число доступных серий.
5. Цвет статуса применяется одинаково к полоске, выбранной кнопке, фильтру и статистике.
6. Поиск остаётся привязанным к строке, имеет почти непрозрачный graphite-фон и не превращается в полноэкранное окно на desktop.
7. На мобильном композиция проектируется отдельно, а не получается простым сжатием desktop-сетки.

## Карта решений по компонентам

| Семейство | Основные референсы | Решение Anime Graphite |
|---|---|---|
| Навигация и поиск | Оригинальный Kitsu, Raycast, Radix UI | Поиск раскрывается непосредственно под строкой; поверхность почти непрозрачная, результаты и фильтры остаются одним keyboard-сценарием. |
| Hero и сезон | Оригинальный Kitsu, Apple TV, Netflix | Sharp-art имеет мягко растворённые края, текст держится в safe-area, а выразительность создаётся кадром и контрастом вместо огромной карточки. |
| Постер и статусы | AniList, Letterboxd | Размер фиксируется плотностью `7/6/5/4/3`; серии и оценка остаются под названием, статус — полноширинная полоса, меню полностью живёт внутри постера. |
| Расписание | Apple HIG layout, Primer layout | Неделя читается как горизонтальная шкала, релизы — как единая временная линия, боковая колонка содержит только уведомления и изменения. |
| Обновления | Linear, MUBI | Лента строится хронологически, записи нумеруются и разделяются временем; карточная сетка не используется. |
| Коллекции | MUBI, Letterboxd | Верх страницы показывает живой веер подборок, ниже коллекции имеют разный масштаб и редакционную композицию. |
| Профиль и аналитика | AniList, Primer data visualization | Круглый аватар остаётся по центру; активность находится слева, статистика и точный недельный график — справа. Цвет графика поддерживает смысл просмотра, а не декоративный accent. |
| Меню и motion | Radix UI, Linear | Появление идёт из точки происхождения, занимает `180–230 ms`, сохраняет focus/keyboard-поведение и отключается через `prefers-reduced-motion`. |

Проверяемые первичные источники: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines), [Radix Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu), [Primer Layout](https://primer.style/product/getting-started/foundations/layout/), [Primer Data Visualization](https://primer.style/product/ui-patterns/data-visualization/), [Linear design refresh](https://linear.app/now/behind-the-latest-design-refresh).
