# Kitsu v3 — короткие правила

Палитры: тёмная «Сакура» по умолчанию (`#0e0b12`, лаванда `#c4a1ff` + сакура `#ff9ccb`) и «Обсидиан» (`html[data-palette="obsidian"]`, `#09090a`, янтарь `#ffb547`). Свежие правила — в начале `docs/ART_DIRECTION.md` («Kitsu v3»). Где пункты ниже противоречат v3 (киноварь, бумажная офуда, балки тории над заголовками, запрет градиентов и стекла), действует v3.

- Акцент — `--accent-grad` (главные кнопки, выбранное, прогресс). Стекло — `--glass`, `--glass-line` в `public/kitsu-v3.css`.
- Пустых картинок нет: незагруженный постер заменяет генеративная обложка (`paintImageArt` в `public/app.js`).
- Расположение блоков не менять; менять можно только оформление.

## Наследие «Кицунэ»

Полное описание: [docs/ART_DIRECTION.md](../../../docs/ART_DIRECTION.md). Токены: `tokens.css`.

- Весь стиль через CSS-переменные; новые значения добавляй в `tokens.css`, существующие токены не переименовывай.
- Тёмная тёплая основа (тушь), акцент — киноварь `--accent`. Текст на киновари — `--ink`. Контраст текста не ниже 4.5:1, ошибки дублируй текстом.
- `--kitsunebi` только для «в эфире» и текущей серии; `--kin` только для оценки.
- Заголовки и крупные цифры — Dela Gothic One (`--font-heading`), текст — Onest, тайм-коды — JetBrains Mono. Метаданные не мельче 12px.
- Фирменные элементы ровно пять: тории над заголовком секции, офуда по `status`, ханко для `score`, бумага (зерно + сэйгайха), лисий огонь. Не добавляй шестой.
- Радиусы 4/8/10/14 px; кнопки, вкладки, поиск, стрелки 8 px (не круглые), пилюли только у чипов; острые только ханко и офуда. Теней нет (кроме меню и диалогов).
- Анимируй только `transform`, `opacity`, `clip-path`, `filter`; токены `--ease-*`, `--dur-*`; всё отключается в `prefers-reduced-motion`. Без поддержки/JS контент виден сразу.
- Нельзя: фиолетовые градиенты, glassmorphism, неон, эмодзи вместо иконок, Inter, новые функции и данные, смена поведения (слайдер 9 с, свайпы, закладки, поиск, диалоги, фокус).
- Картинка не загрузилась — рамка остаётся с тем же соотношением сторон: тушь, зерно, название шрифтом заголовков.

## Админка (`admin/`)

- Пульт: плотная, быстрая, спокойная. Характер «Кицунэ» в малых дозах; офуда, ханко, зерно и сэйгайха в админку не переносить.
- Киноварь — логотип, главная кнопка экрана, активный пункт меню. `--kitsunebi` — только «происходит сейчас» (выполняющаяся задача, живой прогресс, API онлайн, ближайший запуск, текущая серия). `--kin` (текст `--kin-text`) — «требует внимания оператора». Ошибка/удаление — `--red`, всегда с текстом, в подтверждении назван объект.
- Dela Gothic One только для H1 страниц и крупных чисел; ID, время и числовые колонки — JetBrains Mono, `tabular-nums`, справа.
- Единственный фирменный элемент — балка тории (заголовок страницы, активный пункт меню).
- Тон статуса задаёт только `toneForStatus` / `labelForStatus` в `admin/app.js` (тона success, warning, danger, info, live, neutral). Перед правкой цвета индикатора проверь дубли класса в `admin/styles.css` (ловушка каскада описана в `admin/docs/DESIGN_SYSTEM.md`).
- Не показывать то, чего нет в бэкенде (`admin/docs/FUNCTIONAL_COVERAGE.md`, колонка «Чего не показывать»); время из API — только через существующую утилиту (наивный UTC).
- Состояния: скелетон (спокойный, без бегущих полос), пусто (что делать дальше), ошибка (видимая, повтор только по контракту), «не сохранено» в шапке редактора.
- Анимации: drawer 240 мс `--ease-out`, диалог и палитра `scale .98 → 1` через `@starting-style`, тосты снизу, View Transitions для смены экрана; только transform/opacity/filter; `prefers-reduced-motion` выключает.
