# Kitsu — короткие правила

Полное описание — `docs/ART_DIRECTION.md` (оно единственное; прежние «Кицунэ» и «v3» объединены). Токены — `tokens.css`.

**Палитры:** тёмная «Сакура» по умолчанию и «Обсидиан» (`html[data-palette="obsidian"]`), у обеих есть светлый вариант. Бурых основ нет.

**Принцип:** спокойный интерфейс, акцент только там, где есть действие. Если элемент нельзя объяснить функцией — его нет. Расположение блоков не менять; менять можно оформление.

## Жёсткие правила владельца (проверяются перед каждым PR)

1. Только палитры «Сакура» и «Обсидиан» (и их светлые варианты).
2. Расположение блоков не менять.
3. Иконки не обводить: ни рамок, ни плашек, ни кругов вокруг — ни в покое, ни при наведении.
4. Без эмодзи и текстовых символов-заменителей — только SVG-иконки (lucide).
5. Без круглых и «таблеточных» форм: скругление 2–16 px; круглые только аватары людей.
6. Адаптив 320–1920 px: нет горизонтальной прокрутки, текст в кнопках не переносится, ничего не налезает.
7. Контраст текста ≥ 4.5:1 в обеих палитрах и в светлой теме.
8. Одна функция — один компонент: одно определение в CSS, без второго слоя-усилителя и без своей копии.
9. Данные и запросы не менять; показывать только то, что есть в контракте бэкенда.

## Шаблонность (запрещено; сторож — `tools/design-tells.test.mjs`)

Цветные градиенты кроме заливки главной кнопки и полосы прогресса; градиентный текст; свечение; размытие фона кроме шапки; частицы; наклон и блик за курсором; счётчики-«набегалки»; появление при прокрутке; надписи-кикеры над секциями; узоры-обои и иероглифы-украшения; запасная обложка с «картинкой». Потолки в тесте только опускаются.

## Шкалы

Шрифт `--fs-1…6` и `--fs-h2/h1/hero` (не мельче 12 px). Радиус `--radius-2xs/xs/sm/md/lg` (2/4/8/12/16). Шрифты: Dela Gothic One — заголовки и крупные числа; Onest — текст; JetBrains Mono — время, коды, числа. Анимируются только `transform`, `opacity`, `clip-path`, `filter`; всё выключается при `prefers-reduced-motion`.

## Админка (`admin/`)

Перед правкой прочитать `admin/docs/HANDOFF.md`. Строка таблицы 40–44 px, вся строка — ссылка. Цвет статуса только у ошибки, ожидания и идущего процесса. Тон и подпись — из словаря `STATUS` в `admin/app.js`. `--kitsunebi` — только «происходит сейчас». Не показывать того, чего нет в бэкенде: поле, которое сервер не читает, — с пометкой «не подключено». Время из API — наивный UTC; показывать Asia/Almaty через `contracts.js`. Кнопка с последствиями — через `data-request` и контракт в `contracts.js`. Никаких выезжающих панелей: запись — отдельная страница, мелочи — правка в строке, маленькие формы — диалог по центру.

## Проверка

`npm run manifest:update`, `npm test`, `npm run check`, `npm run build`; скрипты `tools/ui-audit/` (иконки, круглые формы, наведение, эмодзи, контраст, вёрстка на 9 ширинах) должны давать чистый результат. В PR — таблица «признак → было → стало» и запись в `docs/BACKEND_PARITY.md`.
