# Kitsu v3 — короткие правила

Палитры: тёмная «Сакура» по умолчанию (`#0e0b12`, лаванда `#c4a1ff` + сакура `#ff9ccb`) и «Обсидиан» (`html[data-palette="obsidian"]`, `#09090a`, янтарь `#ffb547`). Свежие правила — в начале `docs/ART_DIRECTION.md` («Kitsu v3»). Где пункты ниже противоречат v3 (киноварь, бумажная офуда, балки тории над заголовками, запрет градиентов и стекла), действует v3.

- Акцент — `--accent-grad` (главные кнопки, выбранное, прогресс). Стекло — `--glass`, `--glass-line` в `public/kitsu-v3.css`.
- Пустых картинок нет: незагруженный постер заменяет генеративная обложка (`paintImageArt` в `public/app.js`).
- Расположение блоков не менять; менять можно только оформление.


## Жёсткие правила владельца (обязательны, проверяются перед каждым PR)

1. Тёмная тема — только палитры «Сакура» (по умолчанию) и «Обсидиан». Никаких коричневых/бурых основ.
2. Расположение блоков не менять; оформление, анимации и эффекты менять можно и нужно.
3. **Иконки никогда не обводить**: ни рамок, ни плашек, ни кругов/квадратов вокруг иконок — ни в покое, ни при наведении, ни в открытых меню. Иконочная кнопка меняет только цвет иконки (и тень для читаемости на картинке).
4. **Без эмодзи и текстовых символов-заменителей** (★ ▶ → ⌘ ✓ и т. п.) — только SVG-иконки (lucide).
5. **Без круглых и «таблеточных» форм**: кнопки, ссылки-кнопки, чипы, метки, бейджи, переключатели, точки статусов, полосы прогресса, аватары — прямоугольники со скруглением 2–16 px. Запрещены `border-radius: 50%`, `999px`, `--radius-pill` как «пилюля».
6. Адаптив 320–1920 px: никакой горизонтальной прокрутки, текст в кнопках не переносится на 2 строки, ничего не налезает и не обрезается, отступы ровные.
7. Контраст текста ≥ 4.5:1 в обеих палитрах и в светлой теме.

Проверка: скрипты-аудиты из PR #52 (иконки, круглые формы, наведение, эмодзи, вёрстка на 9 ширинах, контраст) должны давать чистый результат.

## Наследие «Кицунэ»

Полное описание: [docs/ART_DIRECTION.md](../../../docs/ART_DIRECTION.md). Токены: `tokens.css`.

- Весь стиль через CSS-переменные; новые значения добавляй в `tokens.css`, существующие токены не переименовывай.
- Тёмная тёплая основа (тушь), акцент — киноварь `--accent`. Текст на киновари — `--ink`. Контраст текста не ниже 4.5:1, ошибки дублируй текстом.
- `--kitsunebi` только для «в эфире» и текущей серии; `--kin` только для оценки.
- Заголовки и крупные цифры — Dela Gothic One (`--font-heading`), текст — Onest, тайм-коды — JetBrains Mono. Метаданные не мельче 12px.
- Фирменные элементы ровно пять: тории над заголовком секции, офуда по `status`, ханко для `score`, бумага (зерно + сэйгайха), лисий огонь. Не добавляй шестой.
- Радиусы 4/8/10/14 px; кнопки, вкладки, поиск, стрелки 8 px (не круглые), пилюли только у чипов; острые только ханко и офуда. Теней нет (кроме меню и диалогов).
- Анимируй только `transform`, `opacity`, `clip-path`, `filter`; токены `--ease-*`, `--dur-*`; всё отключается в `prefers-reduced-motion`. Без поддержки/JS контент виден сразу.
- Нельзя: фиолетовые градиенты, glassmorphism, неон, эмодзи вместо иконок, Inter, новые функции и данные, смена поведения (слайдер 9 с, свайпы, закладки, поиск, диалоги, фокус).
- Картинка не загрузилась — рамка остаётся с тем же соотношением сторон: тушь, зерно, название шрифтом заголовков.

## Админка (`admin/`, v4)

Перед правкой прочитать `admin/docs/HANDOFF.md`: карта разделов, запросы, находки в бэкенде.

- Пульт: плотно, быстро, спокойно. Ровно один фирменный элемент — балка-градиент у `h1` и у активного пункта меню.
- `--kitsunebi` — только «происходит сейчас»: идущая задача, живой прогресс, отметка «сейчас» на шкале суток. Внимание оператора — `--kin-text`. Ошибка и удаление — `--red`, всегда с текстом и с названием объекта в подтверждении.
- Тон и подпись статуса — только из словаря `STATUS` в `admin/app.js` (`toneForStatus` / `labelForStatus`).
- Dela Gothic One — только `h1`, заголовки разделов и крупные числа; ID, время и числа — JetBrains Mono, `tabular-nums`.
- Не показывать того, чего нет в бэкенде. Если поле есть, но сервер его не читает, — показывать с пометкой «не подключено», а не как рабочую настройку.
- Время из API — наивный UTC; показывать Asia/Almaty через `contracts.js`.
- Иконки без рамок и подложек, в том числе внутри `kbd` и пустых постеров; иконки, нарисованные в круге (`info`, `circle-*`), не использовать.
- Каждая кнопка с последствиями — через `data-request` и контракт в `contracts.js`; новый экран — запись в `sections`, рендерер и маршрут в `tools/ui-audit/admin_routes.py`.
- Анимации: панель 240 мс `--ease-out`, диалог `scale .98 → 1`, смена экрана через View Transitions, только transform/opacity/filter; `prefers-reduced-motion` выключает всё.
