# Kitsu — шаблоны интерфейса

Главная, страница тайтла и административная панель на HTML, CSS и JavaScript. Это демонстрационный интерфейс: данные встроены в шаблон, выбранные настройки сохраняются в браузере.

## Запуск

```sh
npm ci
npm run dev
```

Откройте корневую страницу и выберите пользовательский интерфейс или админку.

```sh
npm run check
npm run build
```

Проверка запускает существующие статические проверки обоих шаблонов. Сборка копирует необходимые файлы в `dist/`. Каталоги `public/` и `admin/` используют общий файл `tokens.css` в корне; сохраняйте эту структуру при размещении.

## Оформление

Цвета, шрифты, радиусы и интервалы определены в `tokens.css`. Описание изменений и проверки: [docs/DESIGN_REFINEMENT.md](docs/DESIGN_REFINEMENT.md).

`tools/visual-review.html` — вспомогательная страница для проверки ширин 375, 390, 768 и 1440 px через iframe. Она доступна при разработке и не входит в сборку.
