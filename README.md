# Kitsu — шаблоны интерфейса

Главная, страница тайтла и административная панель на HTML, CSS и JavaScript. Это демонстрационный интерфейс: данные встроены в шаблон, выбранные настройки сохраняются в браузере.

## Запуск

```sh
npm ci
npm run dev
```

Откройте корневую страницу и выберите пользовательский интерфейс или админку.

```sh
npm run check
npm run build
```

Проверка запускает существующие статические проверки обоих шаблонов. Сборка копирует необходимые файлы в `dist/`. Каталоги `public/` и `admin/` используют общий файл `tokens.css` в корне; сохраняйте эту структуру при размещении.

## Контроль состава сборки

`npm run build` и прямой запуск `node tools/build.mjs` проверяют манифесты до изменения `dist/`. Сборка прекращается при неучтённом публикуемом файле, пропавшем файле или несовпадении контрольной суммы; проверки ничего не перезаписывают.

- Корневой `MANIFEST.sha256` проверяет общие `index.html`, `favicon.svg` и `tokens.css`.
- `public/MANIFEST.sha256` и `admin/MANIFEST.sha256` обязаны покрывать все публикуемые файлы своих каталогов, включая вложенные ресурсы. Ранее перечисленные документы и QA-отчёты также продолжают проверяться.
- Проверка и сборка используют один список из `tools/publish-files.mjs`. В сборку не входят каталоги `docs`, `tools`, `screenshots`, файлы `.md`, `.sha256` и QA-отчёты. Символические ссылки в публикуемых ресурсах не поддерживаются.

После намеренного изменения ресурсов или записи новых QA-отчётов:

```sh
npm run manifest:update
npm run check:integrity
npm test
npm run build
```

`manifest:update` явно обновляет хеши и добавляет новые публикуемые файлы. Пропавшие файлы не удаляются из списков автоматически: при намеренном удалении ресурса нужно удалить и его строку из соответствующего манифеста. Изменённые ресурсы, отчёты и манифесты фиксируются вместе.

## Оформление

Цвета, шрифты, радиусы и интервалы определены в `tokens.css`. Описание изменений и проверки: [docs/DESIGN_REFINEMENT.md](docs/DESIGN_REFINEMENT.md).

`tools/visual-review.html` — вспомогательная страница для проверки ширин 375, 390, 768 и 1440 px через iframe. Она доступна при разработке и не входит в сборку.
