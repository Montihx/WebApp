## A. Текущее состояние

### Что есть

Сайт: главная, каталог (на главной), страница тайтла, вход, профиль, настройки, страница пользователя, закладки. Админка: 37 экранов (маршруты в `tools/ui-audit/admin_routes.py`), боковое меню из 6 разделов + «Настройки», командная палитра, глобальная плашка идущей задачи.

### Общие и дублируемые компоненты

Общее (после PR #105): статус закладки, карточка тайтла, оценка, уведомление, вкладки `.bm-tabs`. Админка — отдельная система (`admin/styles.css`, 83 КБ) со своими кнопками, таблицами, вкладками; связь с сайтом только токены и палитры. Дубли внутри админки и сходство кнопок/вкладок с сайтом **не инвентаризированы** (не сделано).

### Штатные проверки (без ручной оценки)

`npm test` 89/89; `npm run check` — 0 ошибок; аудиты иконок, круглых форм, наведения, эмодзи, контраста — чисто; аудит вёрстки — чисто после правки отступа слайдера (одно найденное и исправленное наложение). Автоматика подтверждает соблюдение правил, но не оценивает качество дизайна.

### Не измерено (признаём явно)

Число шагов в частых сценариях админки; доступность с клавиатуры в ручном обходе; светлая тема — снимки есть, оценка не проведена; ширины 320/768/1920; реальные постеры.
