# Арт-направление Kitsu

Один документ вместо двух прежних слоёв («Кицунэ» и «v3»). Расположение блоков не меняется; здесь описан только внешний вид. Токены — `tokens.css`; сайт — `public/styles.css` (и `public/kitsu-v3.css` для страниц); админка — `admin/styles.css`.

## Принцип

Спокойный тёмный интерфейс, где акцент встречается там, где есть действие: главная кнопка, выбранное, прогресс, статус. Всё остальное — плоские поверхности, тонкая линия и текст. Оформление не должно «играть»: если элемент нельзя объяснить функцией, его нет.

## Палитры

Тёмная по умолчанию — **Сакура**; **Обсидиан** включается переключателем. Выбор общий для сайта и админки: `localStorage["kitsu-palette"]`, атрибут `html[data-palette="obsidian"]`. Есть светлая тема для обеих палитр.

| Роль | Сакура (тёмная) | Обсидиан (тёмная) |
|---|---|---|
| Фон / поверхность / приподнятая | `#0e0b12` / `#15111b` / `#1d1825` | `#09090a` / `#111112` / `#19191b` |
| Линия | `#2c2537` | `#29292c` |
| Текст / вторичный / приглушённый | `#f6f1f7` / `#cbc1d2` / `#a197ab` | `#f5f3ef` / `#bcb8b0` / `#9a968e` |
| Акцент / второй акцент | лаванда `#c4a1ff` / сакура `#ff9ccb` | янтарь `#ffb547` / свет `#ffd98a` |
| «В эфире» `--kitsunebi` | `#7de3ff` | `#7ccbff` |
| Оценка `--kin` | `#ffcb70` | `#ffb547` |

Светлые варианты: «Сакура днём» (`#f7f3f9`, акцент `#6b3fc4`) и «Обсидиан днём» (`#f5f4f1`, главная кнопка — тушь). Контраст текста ≥ 4.5:1 везде; проверка — `public/tools/qa.mjs` и `admin/tools/qa.mjs`.

## Шкалы (всё через токены)

- Шрифт: `--fs-1…6` (12 / 13 / 15 / 18 / 22 / 28 px) и `--fs-h2`, `--fs-h1`, `--fs-hero`. Мельче 12 px нет. Заголовки секций — `--fs-h2`; `--fs-hero` только у героя главной.
- Радиус: `--radius-2xs` 2, `-xs` 4, `-sm` 8, `-md` 12, `-lg` 16. Кнопки, вкладки, поля — `sm`; карточки, диалоги — `sm`/`md`; круглое только у аватаров людей.
- Шрифты: Dela Gothic One — заголовки и крупные числа; Onest — текст; JetBrains Mono — время, коды, числа в таблицах.
- Анимация: только `transform`, `opacity`, `clip-path`, `filter`; токены `--dur-*`, `--ease-*`; всё отключается при `prefers-reduced-motion`. На сайте 8 ключевых кадров (меню, шторка, тост ×2, спиннер, скелет, тряска, смена палитры), в админке 3.

## Что запрещено (это и есть «шаблонность»)

Охранный тест `tools/design-tells.test.mjs` не даёт этому вернуться; потолки только опускаются.

- цветные градиенты кроме двух ролей: заливка главной кнопки и полосы прогресса (`--fill-primary`, `--fill-progress`);
- градиентный текст, свечение (`box-shadow` с размытием цвета акцента), размытие фона кроме шапки;
- частицы, наклон и блик за курсором, счётчики-«набегалки», появление блоков при прокрутке;
- надписи-кикеры над заголовками секций, узоры-обои, иероглифы как украшение;
- запасная обложка с «картинкой» (ночь, луна, город): теперь это плоская плитка с названием;
- эмодзи и символы вместо иконок; иконки с рамкой, плашкой или кругом вокруг;
- «таблеточные» формы: радиус 999 и 50% у кнопок, чипов, меток, переключателей.

## Одна функция — один компонент

Если два элемента делают одно и то же, они одинаковые — по виду, подписи, порядку и поведению. Своя копия «похожего» — дефект. Определение компонента живёт в одном месте CSS; второго слоя с `:root`-усилителем быть не должно.

| Функция | Единственный источник |
| --- | --- |
| Кнопка (главная / вторичная) | `.button` в `styles.css` |
| Вкладки-переключатель | `.tabs`, `.tab`, `.tab-indicator` |
| Статус тайтла, метка типа | `.status-pill`, `.hero-kind-badge` |
| Карточка тайтла | `KitsuContent.animeCard`, `.anime-card`, `.poster-frame` |
| Статус закладки (подписи, порядок, цвет) | `KitsuContent.bookmarkStatuses` |
| Заголовок секции и ссылка «Показать все» | `.section-heading`, `.section-link` |
| Текстовое поле | общий блок `.pf-field` / комментарии в `styles.css` |
| Номер серии | `.episode-chip` |
| Диалог по центру | общая оболочка для `content-dialog`, `titles-dialog`, `title-list-dialog`, `player-settings-dialog`, `pf-dialog` |
| Уведомление | `window.KitsuToast` |

Не сведены и помечены как следующая работа: вкладки-дни расписания (`.day-tab`), вкладки плеера (`.player-tab`), состояние ошибки картинки (`.is-image-error`), `.section-count`, `.continue-heading`.

## Админка

Плотно, быстро, спокойно. Строка таблицы 40–44 px, вся строка — ссылка на запись, повторяющихся кнопок «Открыть» нет. Цвет статуса только у того, что требует внимания: ошибка, ожидание, процесс идёт; «готово», «вышел», «в норме» нейтральные. Подробности и карта разделов — `admin/docs/HANDOFF.md`.

## Правила владельца (поверх всего)

Иконки без рамок и плашек (и при наведении). Без эмодзи и текстовых символов-заменителей. Адаптив 320–1920 px: никакой горизонтальной прокрутки, текст в кнопках не переносится, ничего не налезает. Контраст ≥ 4.5:1. Данные и запросы не менять; показывать только то, что есть в контракте бэкенда.
