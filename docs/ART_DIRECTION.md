# Арт-направление «Кицунэ»

Kitsu → кицунэ. Ночь у храма: тушь, бумага васи, киноварь ворот-тории, холодный лисий огонь (кицунэби), печати-ханко. Тёмная тёплая основа и редкие яркие вспышки. Не манга и не копия чужих сайтов.

Область: **публичная часть** (`public/`). Структура и порядок секций не меняются, меняется визуальный слой. Админка получает те же общие токены, но не перерабатывается (отдельная задача). Весь стиль держится в CSS-переменных `tokens.css`: это эталон для Next.js + Tailwind 4.

## Палитра

## Шрифты

- **Dela Gothic One 400** (`--font-heading`): заголовки, крупные цифры, ханко, wordmark, иероглифы офуда. Файлы `fonts/dela-gothic-one-{latin,cyrillic,japanese}-400-normal.woff2`, собраны `pyftsubset`; японский — только используемые знаки (`放送中完結予告狐火印` + названия из данных шаблона). Лицензия OFL: `fonts/DELA-GOTHIC-ONE-LICENSE.txt`. Новый иероглиф или кана в разметке требует пересборки японского файла.
- **Onest** 400–800 (`--font-body`): текст и интерфейс. Manrope удалён.
- **JetBrains Mono**: только тайм-коды.
- Шкала: hero `clamp(2.75rem, 6vw, 6rem)` при `line-height: .95`; H2 секций `clamp(1.75rem, 3vw, 2.75rem)`; кикер 12px, uppercase, `letter-spacing: .14em`, Onest 700; метаданные не мельче 12px.
- Логотип: wordmark Dela Gothic и SVG-тории (`.brand-mark`, `favicon.svg`).

## Фирменные элементы (ровно эти)

1. **Тории** над заголовком секции: два псевдоэлемента киновари, верхний длиннее и толще, с выступами. Кикер и H2 идут под ними.
2. **Офуда**: вертикальная бирка на постере по `status` (`.ofuda`, `writing-mode: vertical-rl`). Иероглифы `aria-hidden`, рядом видимая русская подпись. 完結 — завершён, 放送中 — онгоинг, 予告 — анонс.
3. **Ханко**: оценка `score` в красной печати: поворот −4°, внутренняя рамка, цифры Dela. Нет оценки — печати нет.
4. **Бумага**: общий слой зерна (`body::before`, `--grain-url`, 5–6%) и сэйгайха в hero (`--seigaiha-url`, 5%).
5. **Лисий огонь**: мягкое голубое свечение с мерцанием 3 с — только у live-индикатора и текущей серии.

Геометрия «бумажная»: радиусы 2 px (`--radius-xs/sm`) и 6 px (`--radius-md/lg/xl`), пилюли (`--radius-pill`) только у чипов. Теней нет, кроме меню и диалогов.

## Fallback картинки

Постеры с shikimori.one часто не грузятся. Рамка сохраняет соотношение сторон, фон — тушь, поверх зерно и название шрифтом заголовков (`data-fallback-title` ставит `app.js` по `alt`).

## Движение

| Токен | Значение |
|---|---|
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` |
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` |
| `--ease-ink` | `cubic-bezier(.65, 0, .35, 1)` |
| `--dur-1` / `--dur-2` / `--dur-3` | 140 / 240 / 420 ms |

Анимируются только `transform`, `opacity`, `clip-path`, `filter`. Заголовок hero проявляется «тушью» (`clip-path` слева направо, 600 ms, `--ease-ink`); zoom hero 1 → 1.06 за 9 с вместе с прогрессом; «оттиск» печати 1.25 → .96 → 1 с поворотом; мерцание кицунэби 3 с; ряды появляются лесенкой (16 px, шаг 40 ms) через `animation-timeline: view()` внутри `@supports`. Переход карточка → тайтл и смена темы — View Transitions как прогрессивное улучшение. `prefers-reduced-motion: reduce` выключает zoom, мерцание, лесенку, проявление и переходы.
