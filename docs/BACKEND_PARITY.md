# Сверка шаблонов с бэкендом и старым фронтом

Живой документ. Источник истины — **код**, не документация:

- бэкенд: `kitsu-enterprise-site/backend-go/cmd/api/main.go` (роуты Go),
  `backend/app/api/v1/endpoints/*.py` (то, что ещё в Python),
  `nginx/nginx.conf` (что куда уходит: всё, что не забрал Go, падает в
  `location /api/` → Python);
- старый фронт: `kitsu-enterprise-site/frontend/app/**/page.tsx` и `components/`.

Первая сверка — 31.10.2026. Отметки: `[x]` сделано в шаблоне, `[~]` частично,
`[ ]` не сделано, `[B]` нужно от бэкенда (шаблон не исправит).

## 1. Шаблон показывал то, чего нет

- [x] **AniBoom в плеере.** Парсера AniBoom нет, это только метка `source` у
  релиза. Вкладки плеера теперь — реальные режимы старого фронта:
  «Встроенный плеер» (HLS через `GET /stream/m3u8`) и «Плеер Kodik» (iframe).
  Источник один — Kodik. *(PR #75)*
- [x] **Подписка «Новые озвучки» (`dubbing`) и «Все обновления» (`all`).**
  Сохраняются, но рассылку об озвучках никто не вызывает
  (`notify_users_new_dubbing` в Python не вызывается, Go шлёт только
  `episode`/`all`). Оставлено «Новые серии» / «Не уведомлять»; сохранённые
  `true`/`all`/`dubbing` показываются как «Новые серии». *(PR #75)*
- [x] **Фильтр «Возраст» в поиске.** У `GET /anime/` такого параметра нет.
  Убран. Параметры каталога по коду: `q, genre, kind, status, year, season,
  min_score, sort_by (score|popular|по умолчанию), page, cursor, limit`. *(PR #75)*
- [x] **Жанры английскими ключами.** В базе жанры — русские названия из
  Shikimori (`merger.go`: `russian`), фильтр — точное совпадение
  `genres ? 'Фэнтези'`. Значения в поиске и меню категорий теперь русские,
  список при переносе брать из `GET /anime/genres`. *(PR #75)*
- [x] **«Выбор редакции».** Признака редакции в базе нет. Блок переименован в
  «Лучшее в каталоге · оценка от 8.5» (`min_score=8.5&sort_by=score`, как
  `FeaturedSection` старого фронта); у слайдера записан источник. *(PR #75)*
- [x] **Уведомления «Расписание изменилось», «Ответ на комментарий».** Бэкенд
  создаёт уведомления одного типа — `new_episode` (`sync_incremental.go`):
  «Новый эпизод: …», «Серия N уже доступна. Озвучки: …», иконка = постер.
  Попап теперь такой. *(PR #75)*
- [B] **`GET /dashboard/parsers/job-types`** — админка берёт реестр операций
  из `admin/data.js`, эндпоинта нет (план 0.3 бэкенда). Записано и в
  `admin/docs/HANDOFF.md`.

## 5. Пробелы бэкенда (передать в kitsu-enterprise-site)

- [B] `GET /interactions/favorites` отдаёт строки без `ORDER BY` — порядок
  плавает; профиль сортирует по `updated_at` сам. Правило постраничных списков
  из CLAUDE.md бэкенда сюда не дотягивает: страниц нет, но порядок не задан.
- [B] Нет счётчиков закладок по статусам: профиль грузит весь список и считает
  сам. Нет и страницы (`skip/limit`) у `/favorites`.
- [B] `GET /watch-history/me` читает не больше 1000 последних строк и режет
  страницы уже после склейки по тайтлу — дальше этого предела истории нет.
- [B] У `GET /watch-stats/daily/me` `days` не проверяется (отрицательное или
  огромное значение проходит), пустые дни не приходят — график дорисовывает их сам.

- [B] Нет удаления тайтла из коллекции.
- [B] Состав коллекции не читается ни одной ручкой: `GET /collections/{slug_or_id}` отдаёт только
  саму коллекцию, без тайтлов (`collection_items` пишет только `POST …/items`). Страницу коллекции
  со списком аниме сделать нельзя; на главной у коллекции — обложка (`cover_url`), а не постеры
  тайтлов, как было раньше в шаблоне.
- [B] «Популярное» (`sort_by=popular`) — это число оценок с Shikimori (`score_count`), не то, что
  смотрят на сайте сейчас; просмотры по дням есть только в админке (`/dashboard/stats/popular`).
  Подборок «недели» нет: публичные коллекции идут только по `updated_at`.
- [B] `bulk/anime update_status` принимает `anons`, а база и синхронизация
  пишут `announced` — после массовой смены тайтл выпадает из «Анонсов».
- [B] PATCH `/anime/{id}` не правит жанры, студии, число серий, ромадзи,
  синонимы (`animeUpdateFields`).
- [B] `maintenance_mode`, `allow_registration` сохраняются, сайт их не читает.
- [B] Пользователь не может сменить имя (только админ).
- [B] `GET /interactions/favorites` отдаёт все закладки разом, без страниц и без `ORDER BY`; у
  `user_score` нет ручки записи — оценку закладке поставить нечем. «Вернуть» после удаления — новый
  POST, поэтому `created_at` и `updated_at` у вернувшейся закладки новые.
- [B] Поле `rating` (возраст) есть в API, но синхронизация с Kodik его не заполняет
  (`kodiksync/mapping.go` читает только `shikimori_rating` — это оценка); в `material_data`
  Kodik есть `rating_mpaa` и `minimal_age`. Пишется только руками в админке, свободной строкой.
- [B] В Anime нет страны, длительности серии, первоисточника и автора — у конкурентов
  они в шапке тайтла.
- [B] `GET /anime/{slug}/last-update`: `ORDER BY r.created_at DESC LIMIT 1` без второго ключа —
  при двух релизах в одну секунду «Добавлено» может показывать то один, то другой.
- [B] `POST /interactions/follows/{id}` переключает подписку, а не ставит её:
  два одинаковых запроса подряд (двойной клик, повтор после обрыва) возвращают
  всё как было. Шаблон блокирует кнопку до ответа и верит только ответу.
- [B] Списки подписчиков/подписок: без `total`, `ORDER BY` по id пользователя
  (не по дате подписки), `limit` без верхней границы, отрицательный `skip`
  проходит; в список попадают и отключённые пользователи, чей профиль отвечает 404.
- [B] У чужого профиля нет публичных закладок и коллекций: `/collections/public`
  не фильтруется по автору, `/favorites` — только свои.
- [B] `PUT /users/me` пропускает ключи со значением `null`: снять аватар или
  обложку можно только пустой строкой (`avatar_url: ""`), соцсеть — тоже `""`
  (preferences сливаются, пропущенный ключ остаётся). Рабочий проект шлёт `null`
  и `undefined`, поэтому «Удалить аватар», сброс пола и очистка соцсетей там
  молча не работают. Шаблон шлёт `""`.
- [B] `active_avatar_id` нельзя сбросить: `null` пропускается, `""` даёт 422.
  Рабочий проект `active_avatar` нигде не показывает; шаблон пишет выбор из
  коллекции ещё и в `avatar_url` и показывает только его.
- [B] Длина пароля проверяется в байтах (`len()` в Go): «8–128 символов»
  для кириллицы на деле 4–64. Шаблон считает байты и пишет об этом.
- [B] `POST /users/me/avatar` и `/cover` сразу записывают картинку в профиль,
  до `PUT /users/me`: сохранение не атомарно. Файл сохраняется как `.jpg` без
  перекодирования, у GIF остаётся только расширение.
- [B] Соцсети в `preferences` не проверяются: туда можно положить любую ссылку.
  Шаблон проверяет имя и домен и хранит только имя.
- [B] `theme_settings` на сервере есть, шаблон хранит тему в браузере.
- [B] Рассылка «новая озвучка» не вызывается нигде.
- [B] Лента комментариев не говорит, лайкнул ли текущий пользователь
  (`liked_by_me` нет) — после перезагрузки сердечко не знает своего состояния.
- [B] Лента исключает удалённые (`WHERE is_deleted = false`), поэтому ответы
  на удалённый комментарий остаются без родителя. Шаблон показывает на его
  месте «Комментарий удалён», но с сервера такая строка не придёт.
